# 日出日落智能闹钟 — 设计文档

## 项目概述

一款基于日出日落时间设置闹钟的 Android 原生应用。用户可以选择在日出或日落时触发闹钟，并支持设置偏移时间（提前或延后）。应用采用本地天文算法为主、网络校准为辅的时间计算策略，确保离线可用性。

---

## 目标用户

- 晨型人/早起爱好者（自然醒）
- 摄影爱好者（黄金时刻提醒）
- 户外运动爱好者（日照时间规划）
- 通用用户（任何需要根据日出日落安排日程的人）

---

## 技术栈

- **语言**: Kotlin
- **UI 框架**: Jetpack Compose + Material Design 3
- **架构模式**: MVVM
- **数据持久化**: Room 数据库
- **系统闹钟**: AlarmManager + BroadcastReceiver
- **后台任务**: WorkManager
- **定位**: FusedLocationProviderClient (Google Play Services)
- **天文计算**: 本地算法库（如 suncalc4j 或自研算法）
- **国际化**: Android 资源本地化（values/strings.xml）

## 核心功能

### 1. 闹钟管理

- 支持创建多个闹钟
- 每个闹钟基于**日出**或**日落**时间
- 支持偏移量设置：-2小时 ~ +2小时，精确到分钟
- 标准重复模式：仅一次、每天、工作日、周末、自定义星期
- 闹钟开关、编辑、删除
- **滑动删除**：左滑卡片显示删除按钮，点击确认删除
- **展开互斥**：同一时间仅允许一个卡片展开删除区域，其他操作自动收起

### 2. 日出日落时间计算

- **本地计算**：使用天文算法，根据用户经纬度实时计算任意日期的日出日落时间
- **网络校准**：WorkManager 定时任务，联网时从天文 API 获取准确时间进行校准
- **优先级**：本地计算优先，网络校准仅用于修正微小偏差

### 3. 定位策略

- **自动定位**：通过 GPS/WiFi 获取当前位置
- **手动选择**：从城市列表中搜索并选择（精确到城市）
- **灵活切换**：首次使用引导选择，后续可在设置中随时切换
- **无需强制定位权限**：用户可完全通过手动选择城市使用应用

### 4. 响铃行为

- **响铃模式（用户可选）**:
  - 全屏响铃（标准闹钟界面）
  - 普通通知模式（通知栏提醒）
- 贪睡功能（Snooze）：默认 5 分钟，可配置
- 铃声选择：系统铃声或自定义铃声
- 振动开关
- 渐强铃声

### 5. 可靠性保障

为保证闹钟在应用被系统回收后仍能正常响铃，采用多重保障机制：

| 层级 | 机制 | 说明 |
|------|------|------|
| 第一层 | `setAlarmClock()` | 系统级闹钟 API，锁屏显示闹钟图标，最可靠 |
| 第二层 | 电池优化白名单 | 引导用户将应用加入系统电池优化白名单 |
| 第三层 | 前台服务 | 响铃前 15 分钟启动前台服务，提升进程优先级 |
| 第四层 | 开机自启 + 定时自检 | 开机重新注册；每天检查闹钟注册状态，丢失自动恢复 |

### 6. 深色模式

- 跟随系统（默认）
- 强制浅色
- 强制深色

### 7. 国际化与本地化

- 默认语言：英文（`values/strings.xml`）
- 中文支持：简体中文（`values-zh-rCN/strings.xml`）
- 所有 UI 文本通过 `stringResource()` 或 `context.getString()` 引用，便于扩展其他语言
- 日期格式、数字格式等遵循系统 Locale

## UI 设计

### 设计原则

- 简洁为主，减少认知负担
- 尽量减少子页面，主要操作通过底部弹窗完成
- 支持响应式布局，适配手机和平板

### 页面结构

#### 主页面（闹钟列表）

顶部区域：
- 当前定位城市
- 今日日出、日落时间预览
- 设置入口（齿轮图标）

列表区域：
- 闹钟卡片列表，每张卡片显示：
  - 图标（日出/日落）
  - 闹钟名称
  - 基准描述（如"日出 - 30分钟"）
  - 实际响铃时间
  - 重复模式
  - 开关状态
- **滑动交互**：左滑卡片显示红色删除区域，点击删除按钮执行删除
- **自动收起**：滚动列表、点击其他卡片、切换开关、打开设置/添加弹窗时，自动收起展开的删除区域

底部：
- 浮动添加按钮（+）

#### 添加/编辑闹钟 — 底部弹窗

- 顶部标签切换：日出 / 日落
- 偏移量滑块（-2小时 ~ +2小时）
- 列表项：重复模式、铃声、贪睡
- 每项点击后从底部弹出选择器
- **高级设置** 按钮：点击进入新页面，包含振动开关、响铃音量、响铃时长、节假日跳过、响铃模式选择（全屏/通知）
- 底部：保存按钮

#### 设置 — 底部弹窗

- 深色模式选择（跟随系统/开/关）
- 位置设置：当前城市、GPS 定位开关、手动选择城市
- 时间校准：上次校准时间、立即校准按钮
- 关于：版本信息

### 响应式布局

| 屏幕类型 | 布局方案 |
|---------|---------|
| 手机（<600dp） | 单列列表 + 全宽底部弹窗 |
| 折叠屏展开（>600dp） | 双栏布局：列表 40% + 详情 60% |
| 平板横屏（>840dp） | 双栏布局：列表 35% + 详情 65% |
| 平板竖屏 | 同手机，单列 + 底部弹窗 |

## 数据模型

### Alarm（闹钟实体）

```kotlin
@Entity
data class Alarm(
    @PrimaryKey val id: String,
    val name: String,              // 闹钟名称
    val baseType: BaseType,        // SUNRISE 或 SUNSET
    val offsetMinutes: Int,        // 偏移分钟数（可为负）
    val repeatDays: List<Boolean>, // 周一到周日
    val ringtoneUri: String?,      // 铃声URI
    val snoozeEnabled: Boolean,   // 是否开启贪睡
    val snoozeMinutes: Int,        // 贪睡间隔
    val ringMode: RingMode,        // 响铃模式：FULL_SCREEN / NOTIFICATION
    val isEnabled: Boolean,       // 开关状态
    val createdAt: Long            // 创建时间
)

enum class BaseType { SUNRISE, SUNSET }
enum class RingMode { FULL_SCREEN, NOTIFICATION }
```

### Location（位置实体）

```kotlin
@Entity
data class Location(
    @PrimaryKey val id: String,
    val name: String,              // 城市名称
    val latitude: Double,          // 纬度
    val longitude: Double,         // 经度
    val isAutoLocated: Boolean,    // 是否通过GPS自动定位
    val lastCalibratedAt: Long?    // 上次网络校准时间
)
```

### AppSettings（应用设置）

```kotlin
data class AppSettings(
    val darkMode: DarkMode,            // SYSTEM / LIGHT / DARK
    val currentLocationId: String,
    val lastNetworkSyncAt: Long?
)

enum class DarkMode { SYSTEM, LIGHT, DARK }
```

## 核心流程

### 添加闹钟流程

```
用户点击 "+" → 弹出添加弹窗
    ↓
选择日出/日落 + 偏移量 + 重复模式 + 铃声 + 响铃模式
    ↓
点击保存
    ↓
保存到 Room 数据库
    ↓
计算下次响铃时间（本地 SunCalc 算法）
    ↓
通过 AlarmManager 注册系统闹钟
    ↓
返回主页，列表刷新
```

### 每日自动更新流程

```
每天 00:01（WorkManager 定时任务）
    ↓
获取当前位置和日期
    ↓
计算当日日出日落时间
    ↓
遍历所有已启用的闹钟
    ↓
重新计算每个闹钟的下次响铃时间
    ↓
更新 AlarmManager
    ↓
（可选）联网校准，对比差异
```

### 响铃流程

```
AlarmManager 触发 → 系统广播唤醒应用
    ↓
根据用户选择的响铃模式启动：
    - 全屏模式 → 全屏响铃 Activity
    - 通知模式 → 高优先级通知
    ↓
播放铃声 + 震动
    ↓
用户操作：关闭 / 贪睡 / 超时自动停止
```

## 风险与注意事项

1. **定位精度**：手动选择城市时，使用城市中心坐标可能导致边缘地区时间偏差。建议允许用户微调经纬度。
2. **国产 ROM 兼容性**：华为、小米等厂商对后台限制较严，需要充分测试多重保障机制的可靠性。
3. **天文算法精度**：本地算法与网络数据的微小差异需要处理，避免用户困惑。
4. **时区处理**：跨时区旅行时需要正确处理日出日落时间的时区转换。
